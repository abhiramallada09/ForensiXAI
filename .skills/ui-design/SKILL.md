# UI Design Skill

Design rules for ForensiX AI matching the approved reference design:
- Premium Cyber Forensics aesthetic:
  - Deep Navy/Obsidian sidebar (`#0B132B`, `#0d172e`) with glowing fingerprint shield logo.
  - High-clarity workspace canvas (`#F4F7FC` / `#EEF2F8`) with crisp card containers (`#FFFFFF`), subtle border accents (`#E2E8F0`), and gentle elevation shadows.
  - Electric Blue / Cyan primary accents (`#1E50FF`, `#00C2FF`) for interactive elements, focus states, and primary actions.
  - Semantic status colors:
    - `OBSERVED`: Emerald green (`#10B981`)
    - `CORRELATED`: Indigo / Blue (`#3B82F6`)
    - `RECONSTRUCTED`: Violet / Purple (`#8B5CF6`)
    - `SUSPICIOUS`: Coral / Crimson (`#EF4444`)
    - `UNKNOWN`: Muted slate (`#64748B`)
- Clean typography with strong information hierarchy and precision tabular layouts.
- Avoid cluttered gaming graphics, noisy neon blooms, glassmorphic blur overflows, or unnecessary decorative animations. Keep it looking like high-tier enterprise DFIR software.
